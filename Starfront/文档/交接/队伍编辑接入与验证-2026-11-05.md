## 入口与接线

窗口标识为 `default/mainView/TeamEditPanel`，正式预制体在 `Project/Assets/Prefab/default/mainView/TeamEditPanel.prefab`。代码统一位于 `Project/Assets/Scripts/csharp/main/teamEdit/`，属于 Main 程序集。

主界面按钮调用并 await：

```csharp
await TeamEditControl.OpenAsync(RefreshSavedTeam);
```

调用方应捕获加载或存档读取异常并在主界面提示，不能假报窗口已经打开。重复打开不叠窗，在途打开可用 `TeamEditControl.CancelPendingOpen()` 取消。

读取主界面要显示的已保存、已选用方案：

```csharp
int[] slots = TeamEditControl.ins.ReadSelected(out int schemeNumber);
```

编号为 1—4，数组固定四位；0 是空位，必须保留位置，禁止压缩数组。此 API 返回副本。新方案文件不存在时四套全空，选用编号1；解锁卡牌不自动上阵，不从旧五方案静态预览迁移虚构队伍。

`OpenAsync` 的回调只在本窗口成功保存后触发。也可订阅 `TeamEditControl.ins.model.Saved` 获得成功通知；二选一，避免重复刷新。订阅必须随主界面开关成对注销。回调中重新读取编号与四位数组，不读取窗口草稿。

关闭使用 `TeamEditControl.RequestClose()`，保留未保存确认。来源页切换前如弹窗仍开着，先让用户处理该确认；不要用 `PanelMgr.ClosePanelByType` 或批量 CloseAll 绕过草稿提示。编辑页 Esc、关闭按钮和外部遮罩共用同一流程。

## 交互与提交语义

- 单击上阵位选中，再点牌库卡替换；再点另一上阵位换位（含空位）。再次点同一槽取消选择。
- 牌库中点击已上阵卡：没有其他目标槽时下阵；选中另一槽时换位。满四张但未选目标时提示先选替换位，不擅自替换。
- 一键下阵仅清当前草稿。保存才提交该方案与顺序，同时将它设为已选用方案；允许全空。
- 切换方案只打开该方案草稿，不立刻改变已选用编号。有修改时切换或关闭显示“放弃修改并继续／继续编辑”，不自动保存。
- 保存重新校验容量、重复、拥有、兵种与生产建筑及当前等级战斗数据。失败保留草稿、旧存档、已选编号和revision，不触发成功刷新。
- 默认配置顺序；品质或等级首次点击降序，再次点击反转，同值按配置顺序、再按ID稳定排序。
- 列表含未拥有卡，灰框、压暗、锁图标与未解锁文案；不可加入。固定建筑不列入编组。

## 存储与数据缺项

当前正式配置只有远征步兵1101具备可出战数据，并且只支持已配置的1—3级。其余九张收藏卡即使解锁，也会被battleEnabled或缺少战斗配置拒绝。不得把测试用四卡状态机样例写入正式配置。

职业字段及逐建筑建造费用尚未交付。职业筛选逻辑已支持单选与业务映射查询，`TeamEditQuery` 构造器可接收1先锋／2火力／3重装／4支援的显式查询；正式入口当前未配置该查询，所以非“全部”筛选明确提示数据未提供，不把标签当职业。品质权重来自现行Quality枚举，等级来自CardCollectionModel。费用显示“—”，不拿格子解锁费用冒充建筑费用。

上阵区复用现有Formation静态资源及其Sprite脚底pivot；没有新造Stand动画。牌库复用CardImage、既有品质框和锁定材质。窗口为640×1030独立内容，遮罩覆盖实际舞台，使用公共PanelSafeContent；源设计图只读。现有组件组合是可运行候选，未宣称参考稿视觉或Figma阶段已获新批准。

# 全局滚动提示规范

状态：现行。2026-11-06用户批准单行文字与黑色半透明渐变视觉、插件v2.1结构，后确认“未改结构，按插件 v2.1”。适用于一般瞬时反馈和警告；需用户选择的确认框保持原有流程。

## 显示与动画

- 独立全局宿主，不嵌入业务页面布局。层级19050，高于普通窗口、技能Tips和19040通用确认框，低于19100加载层；不抢键盘焦点，不拦截鼠标或触摸。
- 复用720×1280设计空间及公共PanelSafeContent／UIScreenRegions。条目水平居中，最新一条停留中心在安全内容中心上方120设计像素；旧条在上，每条高44、间距12，同时显示条数读取常量1300，当前为3条。视窗、安全区和平台胶囊变化由既有公共机制处理，不固定手机像素偏移。
- 每条始终单行。26号TMP，普通白色、警告浅金色#FFDC8C；宽度按文字首选宽度+104调整，限制300～640。两侧文字内边距各52，超长文字缩至最低18号，仍超宽时省略；输入换行转换为空格，关闭RichText。调用方应提供简短、可理解文案。
- 背景黑色，中央Alpha0.72，两端各64设计像素平滑渐隐；复用ToastGradientGraphic生成顶点Alpha，不生成位图或图集。必须具备CanvasRenderer。文字使用 fontBodyCommon 及其自带的默认材质。GlobalToastItem 预制体与 GlobalToastIntegration 生成脚本须保持一致。
- 入场0.20秒：透明度0→1、从停留位下方20像素上移，OutQuad；停留1.0秒；退出0.35秒：再上移28像素、透明度1→0，InQuad。条目背景与文本一起移动和淡出。完整时长1.55秒。

## 字体效果与真机回归

- 共用提示新增描边、投影等字体效果时，先用代表性提示在实际发布目标验证，再推广到共用组件。微信小游戏以手机运行对应内容版本的结果为准。
- 改动提示字体、备用字体、材质、着色器或相关打包配置后，使用材料不足的测试卡，在培养页连续点击解锁或升级。逐条检查“材料不足”四字在入场、叠加和淡出期间均清晰可读，无紫块、缺字或异常底色。
- “材料不足”是固定回归文案，当前“材、不、足”取自主字体，“料”取自备用字体。若字库覆盖变化，保留原文案并补充能覆盖新主备组合的样例。
- 验收记录写明微信底座、内容版本、触发入口及真机结果。2026-11-10 内容版本 20261110T065256722Z 已由用户确认文字显示正常。

## 连续调用与生命周期

- 同时显示条数读取ConfigValueResource的1300（普通整数，正整数，当前3）；配置未初始化的启动阶段暂用3条，初始化后严格读取配置，不静默掩盖缺项或非法值。等待队列最多10条，FIFO；新条在下，旧条按槽位上移。每次调用独立产生一条提示，相同内容、相同类型也不合并；达到可见上限后逐条排队，等待满额仍忽略新提示并记录诊断。已有条目用0.18秒OutQuad平滑向上让出56设计像素槽位；连续点击更换目标时，从当前实际显示位置继续，不跳回原起点。槽位让位与每条自己的入场／停留／淡出计时独立，重新让位不延长消息寿命。新条目先在上方条目实际位置下方至少56像素处淡入，随空间腾出归位，全程保持至少12像素净间距，避免穿插。
- 首次调用合并资源在途加载，失败清理等待消息并允许后续重试。Clear／Shutdown使旧加载代次失效，避免迟到回调重新打开宿主。
- 普通界面切换和CloseAll保留宿主，已发提示继续播完；消息结束立即回池，池容量跟随当前显示上限；配置容量缩小时回收最旧可见项并裁减多余池对象。窗口关闭、对象销毁清理Timer监听；复用恢复文字、颜色、尺寸、位置、透明度及动画时间。
- 登出或重建UI根节点前调用GlobalToast.Shutdown；同进程登录初始化也执行重置。Clear只清空本轮活动及等待消息，不关闭正常宿主。所有入口由Unity主线程调用。

## 公共接口与资源

```csharp
GlobalToast.Show("队伍已保存，已选用方案 1");
GlobalToast.Warn("卡牌未解锁");
GlobalToast.Warn(reason); // 资格、容量、保存结果仍由原业务接口决定
GlobalToast.Clear();
GlobalToast.Shutdown(); // 登出／UI系统重置
```

入口：Assets/Scripts/csharp/login/common/GlobalToast.cs，供Login与Main共用；Foundation不引用业务层。GlobalToastPanel／GlobalToastItem位于login/common/view，两个Prefab位于Assets/Prefab/title/common，进入title Addressables组，使用现有ResourceLoader、ResourcePresentation、PanelMgr和UIBinder，不另建加载或字段生成框架。

最小成员集：宿主导出boxMessages和itemTemplate（均RectTransform）；条目导出txtMessage（TextMeshProUGUI）；静态渐变背景不导出。itemTemplate引用独立GlobalToastItem Prefab。成员由原UIBinderInspector生成器维护。ReceivesPanelInput默认为true，被动提示宿主设为false；PanelMgr仍按layer绘制排序，只在选键盘目标时排除被动宿主。

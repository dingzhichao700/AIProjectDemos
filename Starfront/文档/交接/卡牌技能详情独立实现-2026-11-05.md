## 给卡牌培养界面的调用约定

培养页已完成配置及玩家进度初始化后，按当前卡牌和固定入口调用：

```csharp
await CardSkillDetailControl.OpenAsync(currentCardId, CardSkillSlot.Passive);
```

`CardSkillSlot`为`Basic / Passive / Active / Ultimate`，分别对应普攻/被动/主动/大招。入口标识不等同于战斗触发枚举，不按技能数组下标猜测。`skillId=0`使用正式查询解析；已有明确所选技能ID时可以传入，但必须属于此卡且类型匹配。

```csharp
await CardSkillDetailControl.OpenAsync(currentCardId, selectedSlot, selectedSkillId, OnSkillDetailClosed);
```

`OpenAsync(int cardId, CardSkillSlot slot, int skillId = 0, Action onClosed = null)`返回Task。卡牌培养界面需await并按已有浮动提示方式处理加载/身份校验失败；加载期间沿用自身的防重复请求状态。入口不根据卡牌/技能锁定状态禁用查看。

关闭方式：右上角按钮、弹窗外遮罩、Esc；来源页离开/销毁或切卡取消尚未完成的打开时调用`CardSkillDetailControl.Close()`。连续打开使用请求版本废弃旧的加载结果；Close同时取消尚未完成的打开。

弹窗不关闭、重建或切换培养页，不修改卡牌、筛选、滚动或材料状态。`onClosed`在真正关闭后通知一次，卡牌培养界面按需恢复入口焦点；无需重新打开培养页。若无额外恢复动作，可不传回调。培养页应使用低于SCALE_TIP_FIRST的正常界面层，避免把自身放到弹窗之上。

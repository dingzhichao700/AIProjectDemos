# 项目规范索引

每项开发任务先读取根目录 [AGENTS.md](../../AGENTS.md) 和本索引，再按任务范围读取全部相关规范及其引用文件。跨领域任务需要同时读取相关通用规范与专属规范。

统一先读 [规范管理与冲突处理规则](通用规范/规范管理与冲突处理规则.md)：优先关系、必须/默认/建议、生效与替代关系、验收范围。

## 目录与维护原则

- `通用规范/`：可复用于其他项目的开发规则。
- `专属规范/`：仅适用于星域前线的玩法、界面、美术及资产约定；配套参考图和数据随规范保存在本目录。
- 原始配置表仍在 [`文档/配置表`](../配置表/)，不放入规范目录。
- 同一规则只维护一处；新增或移动文档时同步索引、AGENTS.md 和交叉引用。
- 目录整理与内容修订分开记录；生效与替代按规范管理规则处理，不凭修订日期自行覆盖旧约定。项目规范更新不代表外部模板工具链已同步。

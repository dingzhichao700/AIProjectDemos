# 场景美术设计与验证规范

确认日期：2026-10-21。适用于通过对话进行的场景整体或局部试绘、概念预览、灰度、上色、素材替换、修复与合成；不只约束最终资源导出。与[阶段性设计验证流程规范](阶段性设计验证流程规范.md)配合使用。项目具体尺寸、视觉基准与例外在专属规范中维护。

## 一、启动与执行约定

- 每轮先读取项目 AGENTS.md、规范索引、本规范及相关专属规则；不能仅凭聊天记忆或 Skill 提示词执行。
- 执行前用简短白话明确：本轮目标、输入基准、可修改项、锁定项、产物类型、实际尺寸与验收标准。术语服务于意图，不替代修改范围和交付物确认。
- “试一下”“局部看看”“上色”“修正”均不默认解除既定几何约束。有实质歧义时先澄清，不擅自扩大范围。
- 从最近通过的基准开始，保留原版并按版本记录；用户只认可造型或方向时，不能同时宣称尺寸、布局或最终素材已通过。

## 二、标准几何先于美术

- 标准格子来自项目唯一几何基准文件：包含顶点、方向、坐标步长及锚点。仅宽高数值、素材外形或截图观感不足以重建标准格子。
- 先按基准程序生成黑色格线底稿及布局数据，检查等尺寸、合法邻接、位置、障碍占格和视窗。整体图与局部图使用相同坐标规则。
- 通过后锁定几何。图像模型可生成材质和素材外观，但不负责重新决定格子形状、数量、坐标或视窗比例；最终按数据进行确定性合成。
- 黑色格线是几何的可视化检查层，不是几何权威本身。生成图即使画有黑线，也必须重新检查其位置，不能据此认定合规。
- 修改已确认的尺寸或坐标必须有用户明确的新要求，并同步基准、样例与检查结果；禁止在美术修复中悄悄修改几何。

## 三、占格、落脚范围与视觉高度

- 分别记录逻辑占格、地面接触范围、图像画布、定位锚点、可见轮廓及高度投影。透明留白不用于决定主体大小。
- 有高度的地形以地面接触边缘匹配地块；高度产生的视觉越界不等于新增逻辑占格。不得为了容纳整张图像而缩小、压扁或沿地块裁切实体。
- 允许的越界方向、遮挡关系和具体幅度按项目及资产约定执行，不能从某个案例推广到全部对象。
- 低于地面的地形按占格联合边界确定开口，内部视觉如何连续由专属规则定义。
- 同一光照、视角和尺度用于地面、岸壁、岩体与其他实体；固定网格不能因表现斜俯视而出现远近缩放。

## 四、源素材与合成

- 使用干净独立源素材，保留来源、处理脚本、缩放参数和锚点。图集裁切、透明处理、等比缩放及坐标合成应可复现。
- 禁止从带有格线、视窗框、文字等辅助信息的完整效果图中裁取正式素材；辅助线必须独立叠加。
- 禁止以非等比拉伸、径向变形、裁掉主体或拼出断裂岸线来强行适配新占格形状。缺少对应素材时，按正确几何制作素材，不用失真的临时拼接冒充完成。
- 普通地面可以按其地块遮罩合成；高于地面的实体必须使用自身透明轮廓和地面锚点，不能套用地面裁切规则。
- 地面格线随地面绘制并被实体自然遮挡。需要检查实体占格时，另交诊断叠加图并明确标注，不能把穿过实体的校验线当作最终场景表现。

## 五、产物与显示

| 名称 | 用途与约束 |
|---|---|
| 逻辑布局图 | 表达格子区域、类型与邻接，可缩放排版；坐标及占格数据必须准确。 |
| 概念预览 | 验证造型、材质或视觉方向；高分辨率源图不等于实际尺寸效果图。若涉及既定布局，仍须遵守其几何约束。 |
| 1:1验证图 | 1设计单位对应1图片像素，按标准坐标合成并检查；视窗图由完整图按配置直接裁切，不二次缩放。 |
| 放大细节图 | 用于检查细节，必须标明倍率并与1:1图区分。 |
| 素材源图 | 供处理的独立源素材，可高于目标分辨率；不得以它代替1:1验证图。 |

- 同时记录图片尺寸和元素尺寸；大画布内放小素材、整体放大生成图都不能证明比例正确。
- 聊天预览可能自动缩放。交付可下载原图；有必要时提供默认100%且不自动撑满的滚动预览。不得把文件尺寸错误解释为预览缩放问题。

## 六、阶段与交付检查

### 场景拼合验证约定

- 在元素拆分、独立绘制和配置化准备阶段，“生成整体场景看看”“整体效果图”默认指**场景拼合验证图**：使用已确认元素与明确布局数据进行确定性合成，不由图像模型自由重绘整个场景。
- 缺失素材应单独制作和验证。不得为适配已有素材而默默更改已确认布局；确需临时调整时须明确说明并保存独立布局版本。
- 元素清单记录 ID、版本、来源、素材路径、尺寸、逻辑占格、定位锚点及验收状态；布局配置与视觉配置分开管理，不根据外观推导通行、碰撞或建设规则。
- 黑色格线、橙黄色视窗虚线框是独立的设计校验辅助层，可在校验图中强调，在效果图中隐藏。隐藏辅助层不解除几何和尺寸约束；地表自身的接缝明暗属于美术表现。
- 衔接修复优先检查锚点、位移、层级、透明边缘和底层覆盖；不通过重绘、压缩或遮盖已确认元素的特征来掩盖定位问题。
- “暂通过”须记录为阶段性验收，保留可回退版本及未验证项，不自动升级为最终资产入库或运行时验收。

通常依次验证：几何底稿 → 单项素材 → 局部拼接 → 完整场景。可复用已通过阶段，用户明确授权跨阶段时按其范围执行；跨阶段不免除尺寸和几何检查。

自动检查至少覆盖适用的：画布/视窗尺寸、标准顶点和坐标、格子数量与类型、占格互斥、资产缩放/锚点、透明边缘、辅助层分离。
目视检查至少覆盖：接缝、岸线衔接、底部贴合、视觉越界与遮挡、接地感、厚度、残线、材质拉伸、重复纹理及细节尺度一致性。

- 本轮硬性标准不符合时先修复；无法修复应明确报告未完成项，不能仅改称“概念稿”来视为已达标。
- 交付记录输入版本、几何基准、生成方式、处理/合成脚本、产物路径、自动检查、视觉审核、未验证项及下一阶段门槛。
- 不把失败生成图作为默认参考继续重绘；回到最近通过的基准进行针对性修复。
- 完整场景通过、素材入库和运行时通过分别记录。规范写入不代表相关工具或自动化检查已经实现。

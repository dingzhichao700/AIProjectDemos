# 道具表配置规范

适用范围：采用本表结构的项目。具体业务记录由项目维护，不因规范归入通用目录而自动成为模板数据。源表、生成与加载统一遵循[配置表工具链规范](配置表工具链规范.md)和[游戏业务与配置规范](游戏业务与配置规范.md)。

整理日期：2026-10-21。本文区分填写约定与已实现能力；校验要求不代表已有自动校验工具。

## 字段

| 字段 | 填写约定 |
|---|---|
| id | 道具唯一 ID |
| iconId | 图标资源标识，从专门 item 图集或道具散图定位；具体命名与路径由项目确定 |
| name / desc | 名称与说明，不承载执行逻辑 |
| quality | 使用已定义的 Quality 枚举，不以颜色或未定义的 0 代替品质 |
| type | ItemType：常规、积分、消耗品、装备、特殊；以枚举定义为准，0 是有效常规类型 |
| subType | 无细分时填“无”，空值兼容 NONE=0；不把占位枚举视为已有功能 |
| stackMax | 单堆上限，不是背包总数量上限；按类型解释 |

## 堆叠与数量

| 类型 | stackMax | 运行时约定 |
|---|---|---|
| 常规、消耗品、特殊 | 必填非负整数 | 0 表示无限堆叠，正数表示单堆上限 |
| 积分 | 配空，逻辑忽略该字段 | 数量使用 double，表示上限为 double.MaxValue，不接受 NaN/Infinity |
| 装备 | 配空，逻辑忽略该字段 | 不可堆叠，每个实例独立，单堆为 1 |

配置定义与玩家持有数量分离，源表不存玩家库存。积分的 double 数量不能由 int 类型的 stackMax 承载。

## 校验及实现边界

- 检查 ID 唯一、枚举合法、图标可定位、需要填写的堆叠值非空且非负。
- 检查源表空白：部分空数值导出后成为 0，不能只读生成数据就认定“必填”已通过。
- 品质语义与显示颜色分离，不擅自绑定颜色；具体档位和项目货币、碎片关系见[项目道具配置约定](../专属规范/道具配置约定.md)。
- 本次只整理表定义与约定，不代表背包、使用、出售、装备属性或图标加载已实现。

# 战斗场景配置规范

更新日期：2026-10-26。状态：场景1001已通过正式导表、配置加载及Unity运行时地形生成验证；基地、水洼外观与解锁玩法尚未接入。

## BattleSceneResource

一条记录描述一个场景。地块布局在明细表中配置。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 场景唯一 ID |
| name | string | 场景名称 |
| width、height | int | 场景范围宽高，单位为设计像素；不是格子数，也不是设备视窗尺寸 |
| originX、originY | float | 格子 (q=0,k=0) 的中心在场景内的位置，同时为当前旋转对称中心 |
| cameraCenterX、cameraCenterY | float | 初始镜头中心在场景内的位置，单位为设计像素；不使用视窗左上角，避免随设备尺寸变化产生歧义 |
| friendlyBaseQ、friendlyBaseK | int | 己方基地所在格子的整数坐标 |
| enemyBaseQ、enemyBaseK | int | 敌方基地所在格子的整数坐标 |

场景坐标原点为左上角，X 向右、Y 向下。Unity 坐标转换由表现层统一处理。
标准格子尺寸和步进引用 [标准地块几何.json](参考图/场景元素/标准地块几何.json)，不逐场景重复配置。基地建筑资源、种族、属性不在本表定义。

## BattleSceneCellResource

一条记录描述一个初始格子；运行时根据 sceneId 查询并创建。没有记录的坐标不生成格子。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 跨场景唯一的地块配置 ID；不等同于运行时元素 ID |
| sceneId | int | 关联 BattleSceneResource.id |
| q、k | int | 标准六边形加倍坐标；k-q 必须为偶数 |
| camp | BattleSceneCamp | 初始归属：己方 / 敌方 / 绝对中立，与四个种族无关；局内普通格可按战斗规则转移，绝对中立永久不变 |
| type | BattleSceneCellType | 普通 / 山体 / 水洼；决定基础通行规则 |

camp、type 下拉来自对应枚举中文别名，覆盖第4～10000行。不配置初始解锁状态；state、initialUnlocked 及原 unlocked/unlockable 字段均已移除。
所属阵营不通过贴图推导，建筑初始化独立于格子配置。基础通行规则由 type 决定，与外观独立。

### 外观列表的 Excel 布局

BattleSceneResource 的 N～T 列为 *appearances（list,bean.BattleSceneAppearance）。
第 4 行展开 resourceType、resource、layer、cells、anchor、offset；第 5 行仅在 anchor 下展开 q、k。第 6 行为中文说明，数据从第 7 行开始。
资源类型、表现层的下拉覆盖第 7～10000 行，选项从现有枚举定义生成。
每项外观使用一行，cells 保留为单元格内列表字段；其坐标列表序列化填写方式在数据阶段结合正式 Luban 解析验证，不假定字符串可以直接读取。

现有 Bean 及用户修正的格式保持不变，新增枚举沿用用户调整后的块外框、字体及对齐方式。

普通格子允许地面单位通行；山体、水洼不允许地面单位通行，飞行单位均可通过。外观资源不改变此逻辑。可攻击石堆只作预留概念。

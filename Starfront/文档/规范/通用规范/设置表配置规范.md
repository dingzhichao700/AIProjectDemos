# 设置表配置规范

适用范围：采用本表结构的项目。具体业务记录由项目维护，不因规范归入通用目录而自动成为模板数据。源表、生成与加载统一遵循[配置表工具链规范](配置表工具链规范.md)和[游戏业务与配置规范](游戏业务与配置规范.md)。

整理日期：2026-10-21。本文区分填写约定与已实现能力；校验要求不代表已有自动校验工具。

## 当前表结构

`SettingOptionResource` 目前只有以下四个字段；不得将默认值、上下限、候选值或持久化字段描述为已存在的表字段。

| 字段 | 含义 |
|---|---|
| id | 唯一配置记录 ID |
| type | SettingType，设置分类 |
| optionSelection | SettingOptionSelection，具体设置项标识，同时用于保存值的键 |
| optionType | SettingOptionType，控件形式 |

选项形式：SWITCH_OPTIONS=1、SWITCH_BOOL=2、KEY_BIND=3、DRAG_BAR=4。枚举存在不代表每种交互都已实现。

## 表与运行状态分离

- 表定义“有哪些设置项、属于什么分类、采用什么控件”；玩家选择值由存档管理，不回写源表。
- 当前 `SettingOptionCfgMgr` 按分类返回配置；`SaveUserSettingVO.settingMap` 按设置项枚举保存字符串值；`SettingControl` 将值应用到运行环境。
- 默认值目前在 SaveUserSettingVO 初始化逻辑中，非表驱动；当前音量滑条范围 0～100 在界面代码中。后续配置化需要单独变更 Schema 和逻辑，不能只改文档宣称完成。
- 新设置项须同时接入控件、候选值或数值解析、缺省值、保存与恢复以及实际生效处理。只添加一行不能自动获得功能。
- 平台能力分别检查；当前 WebGL 非 Editor 环境不应用桌面分辨率和全屏模式。语言分支当前没有实际应用逻辑，不视为已完成多语言切换。

## 校验要求

- ID 唯一、枚举合法、设置项与控件形式匹配；同一 optionSelection 的重复记录需要明确用途，避免共享存档键导致误联动。
- 检查新存档默认值、修改后生效、重启恢复、非法旧值及平台支持情况。
- 选项候选集合必须覆盖合法存档值；滑条输入检查解析、范围与实际业务单位。
- 扩展默认值和范围等表字段前先对齐规则；本次未增加字段或实现新的校验器。

# Starfront 功能开启配置规范

适用范围：本项目功能开启、锁定入口及单机解锁记录。通用字段和条件语义见[功能开启配置规范](../通用规范/功能开启配置规范.md)。


- 功能一旦解锁即永久解锁。单机模式须在玩家存档中持久化已解锁功能 ID；后续判断先检查已解锁记录，未解锁时才计算配置条件。配置变更为“暂未开放”不自动撤销已有永久解锁记录。
- 未解锁入口保持显示并呈锁定状态；点击弹出开启条件提示，不进入对应功能。
- 功能开启由 Main 程序集下 `function/FunctionControl` 统一处理；`model` 提供查询，View 不自行判断条件或写入解锁记录。
- 单机永久解锁 ID 保存于 `Application.persistentDataPath/functionUnlocks.json`，复用 JSON 持久化工具；重开界面不重置记录。未知功能 ID、未知条件类型应显式失败，不静默放行。
- 等级与通关模块通过 `SetProgressSource` 提供权威查询，并在进度变化后调用 `RefreshUnlocks`。目前两个进度模块尚未落地，未绑定来源时相关条件保持不满足，不虚构等级和通关数据。
- MainPanel 锁定导航仍接受点击并显示条件提示，不切换当前页面；解锁消息触发锁图标刷新。当前只制作卡组和对战内容，其他功能即使已解锁，也只提示页面尚未开放，不增加额外玩法内容。

- 领地（功能 ID 4）当前配置为 DisabledCondition（暂未开放）。

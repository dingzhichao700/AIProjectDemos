# 项目规范索引



每项开发任务先读取根目录 [AGENTS.md](../../AGENTS.md) 和本索引，再按任务范围读取全部相关规范及其引用文件。跨领域任务需要同时读取相关通用规范与专属规范。



统一先读 [规范管理与冲突处理规则](通用规范/规范管理与冲突处理规则.md)：优先关系、条款强度、生效与替代关系、验收范围，以及“进规范”的整合修订流程。



- [卡牌立绘定标与双界面显示规范](专属规范/卡牌立绘定标与双界面显示规范.md)：培养定标立绘/蒙皮1:1设计单位、阵容概念体量缩放；先静态组合审核后改工程，旧倍率迁移边界。



跨专项展示与Unity现场替换：读取[项目规划与统筹职责规范](专属规范/项目规划与统筹职责规范.md) UNITY-SHOWCASE-FLOW-01/R1，区分技术就绪、交验通知和真人保留，不重复批准已授权的自建旧现场替换。



## 目录与维护原则



- `通用规范/`：可复用于其他项目的开发规则。

- `专属规范/`：仅适用于异星军团的玩法、界面、美术及资产约定；配套参考图和数据随规范保存在本目录。

- 原始配置表仍在 [`配置表`](../../配置表/)，不放入规范目录。

- 同一规则只维护一处；新增或移动文档时同步索引、AGENTS.md 和交叉引用。

- 目录整理与内容修订分开记录；生效与替代按规范管理规则处理，不凭修订日期自行覆盖旧约定。项目规范更新不代表外部模板工具链已同步。



涉及任何建筑、单位、山体或装饰物的光照、阴影、底座受影及固定建筑外观，先读[场景光照与阴影规范](专属规范/场景光照与阴影规范.md)：统一C档视觉参数、烘焙／动态分工、实例阴影定位与剔除校验、底座来源及迁移边界。



资源目录及最终Group职责按[目录与分包原则](通用规范/目录与分包原则.md)R3.1；9旧Group迁空及防重建工具合同见[资源统一治理与工具检查规范](通用规范/资源统一治理与工具检查规范.md)NINE-GROUPS/R3.1，未迁记录保持原态。

资源治理职责与执行边界以[项目规划与统筹职责规范](专属规范/项目规划与统筹职责规范.md)“资源治理唯一主责”为准：会话【资源-资源治理与加载性能】统一维护治理及加载性能完整链，架构、发布和制作职责保持分离。




匹配业务接入现行规则见[战斗规则与状态规范](专属规范/战斗规则与状态规范.md)的BATTLE-MATCH-API-01/R1：冻结双方卡组、实际准备进度、取消/失败重试、前台3秒倒计时、唯一移交及共享图片引用归属；本地电脑模拟与联网边界、业务自检和页面真人验收分开记录。

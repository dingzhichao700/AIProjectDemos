# 卡组界面资源引用规范

状态：现行；确认日期：2026-11-02。本篇只定义卡组及相关牌库/选择视图的资源消费契约，业务范围以《卡牌与生产建筑对应规范》现行规则为准，不自行扩展玩法。开发这些视图必须先读[卡牌配套资源规范](卡牌配套资源规范.md)、[卡牌与生产建筑对应规范](卡牌与生产建筑对应规范.md)，并按任务补读UI功能逻辑、界面适配及运行时加载规范。

| 项目 | 使用端规则 |
|---|---|
| 数据入口 | 卡牌身份来自CardResource，预设卡组来自BattleDeckResource；玩家持有与等级读取CardCollectionModel，碎片读取InventoryModel；显示未拥有卡不等于已拥有 |
| 卡面引用 | 新版牌库通过明确的卡牌→artId关联读取CardArtObj.CardImage；CardResource.image保留旧战场链路。正式图缺失时标记占位，不按名称猜资源 |
| 组合职责 | 卡面主体、品质组件、名称和实际业务数值独立组合；不从卡图识别品质，不展示虚构等级/成长数据 |
| 用途规格 | 卡组、牌库、选择分别登记显示尺寸、比例、裁切、安全区、允许缩放；卡面生产与框体/遮罩按[牌库卡面制作与消费规格](牌库卡面制作与消费规格.md)的锁定版本执行。使用端等比显示不改变原生生产规格，外接矩形不能替代真实切角Alpha；160×222仅历史样例 |
| 状态资源 | 列出实际支持的选中、锁定、空槽、不可选等状态及其来源；先核对功能，不因列举而新增状态玩法 |
| 生命周期 | 依既有加载规范声明预加载/按需加载、资源归属、异步返回失效处理、列表复用重置及关闭释放；不可因复用显示上张卡的图片/品质/状态 |
| 双向登记 | 将界面→资源用途→配置入口→规格→接入状态与证据回填共享使用清单；生产端据此交付，不各自另定图像规格 |
| 验收 | 覆盖真实配置卡牌、长名称、各已支持品质/状态、空位、缩放裁切、重复开关及适用的列表复用；与正式卡面美术验收分开 |

当前证据基线：2026-11-02只读核查发现MainPanel静态8张样例尚未接通实际6张测试卡；本规范不宣称当前代码仍未变化，也不以核查记录覆盖其他会话的新实施结果。实施会话须核对当前文件后更新证据。

## 牌库item组件与绑定（2026-11-04）

## 四职业图标与动态数值拆层（2026-11-05）

依据用户本轮要求：职业仅先锋、火力、重装、支援；职业共用底板已接受，图标须独立。策划目录仅只读参考，确认后的约束落在本规范。

- 四职业名称以参考MD及《阵容编组与培养界面规范》为准；“全部”是筛选项，不是第五职业。不得用旧八种tag或准星直接等同先锋，不依据单位外观分配职业。
- 符号识别以源视觉稿带文字标签的筛选栏为依据：先锋为菱形尖角符号，火力为交叉兵器，重装为盾牌，支援为十字。该造型映射为本轮规范化候选，具体透明符号视觉待审；MD只定义职业名称，不能声称MD给出了图标形状。
- 上阵位、牌库、队伍编辑及培养页使用同一职业符号资源身份。底板按用途共用，不为每个职业复制：牌库/队伍编辑/培养存量仍使用圆底板；主阵容上阵位按2026-11-12用户批准的职业铭牌R2改用共用六边底板及独立软投影。四个符号按用户2026-11-05修订独立绘制为纯色扁平矢量，交付SVG母版与透明PNG；不再抠取源图符号，不加金属高光、渐变或立体效果，不含底板或职业名称。职业筛选的文字和状态底板另设，不烘焙在符号中。
- 本轮组件规格：底板32×32；符号透明画布32×32，最大可见包围盒24×24，中心锚点(0.5,0.5)，与底板同中心；保持符号自身长宽比。主阵容六边底板保持32×32显示、128×128透明母版；重装/支援符号围绕中心缩至80%，先锋/火力保持原比例。投影为独立160×160 PNG，显示40×40，相对底板左上偏移(-4,-2)设计像素（屏幕向下为正），黑色55%不透明度、约1px软化、下投2px，默认UI材质；该用途修订不自动改变其他页面。放大筛选显示须声明一致的等比缩放，不分别任意拉伸。
- 费用数字、战力标签、已获得计数、碎片进度必须独立文本，不得导出为带数值的底板。依据用户2026-11-05修订，战力数值改用0–9独立艺术字图片动态拼接，与战力底板及标签分层；不得烘焙整串固定数值。费用上下两处消费同一局内格子解锁成本；文字不得决定费用。 上阵位与牌库卡的局内费用徽章必须是同一公共组件的两个实例，共用同一卡的成本来源、底板、字号、文本对齐与最终显示尺寸。父组件只设置位置。
- 已有无字进度槽与填充优先复用，不能为了拆层重复抠图。进度数值14号粗体、纯白、1px深色描边，在完整槽内居中，与填充长度无关。0值隐藏填充，满值显示完整填充；保持既定槽边界及最大长度。
- 被源文字遮挡的底图修补必须记录范围、源像素依据及待审状态，不能声称还原了不可见原始图层。底板素材不带数字；战力数字图片为前述明确例外。审核组合图可叠加独立文本或数字图片用于验证多值显示。
- 当前只做UI独立素材和文本规格，逐卡职业配置、16卡数据及Unity接入按用户要求后置；组件齐备后再审核整页，不以本轮局部通过扩展为整页/程序/真机通过。

## 上阵位底座与立绘职责（2026-11-11整合）

- 底座是槽位共用UI，空位也常驻；角色独立引用CardArtObj.Formation，底座不烘焙进角色图。地面单位以足底中央、空中单位以本体下方语义锚点对准台面，保持等比，不按透明画布中心猜定位。
- 现行制作目标是共用暗色无光金属底座＋独立品质光效图片，有卡才显示该卡品质光效，绿→蓝→紫→橙四档发光幅度逐档增强。不得新增专用材质替代图片。底座与光效职责分离，不改变卡牌业务品质；旧枚举兼容映射保持。
- 主阵容空位仅留无品质色底座，不显示空位文本、费用、角色、职业、等级或名称；队伍编辑的空位操作提示仍按该窗口规则，不从主阵容推定取消加号。下阵、全空、重开和保存重载均检查底座常驻。
- 有卡时费用、角色、职业符号及底板、等级独立分层；主阵容自2026-11-12批准起不显示上阵单位名称（牌库名称不受影响）。职业铭牌和等级整体相对已通过圆台运行R1下移1设计像素（2026-11-12在下移5px版本基础上，用户先要求上移3px，再上移1px，累计上移4px），置于高于所有上阵台座及角色的统一前景层，坐标随台座跟随，不随角色按压缩放；空位隐藏整项。等级底图若启用也归该层，未批准的新长条底图不得混入。队伍编辑的名称及信息层仍沿用其专项规则。交互按各窗口职责：主阵容点击打开培养，队伍编辑点击下阵，不能因复用表现而复用错误点击行为。
- 历史迁移状态：2026-11-06的四品质合图及灰度材质空位为旧实现，不再作为新资源制作要求；阵容空位已使用无品质图。独立底座/四档光效外观已于2026-11-11获用户“确认采用”，后继R2结构审核及正式接入尚未完成，队伍编辑存量实现需在对应接入任务迁移，文档变更不表示资源/代码已完成。

### 上阵立绘概念体量与跨界面适配（2026-11-11 用户确认）

2026-11-16用途边界修订：以下概念档位仅约束阵容/队伍编辑，不用于培养页跨卡比例。培养定标及静动态1:1统一见[卡牌立绘定标与双界面显示规范](卡牌立绘定标与双界面显示规范.md)。既有数值保留作阵容实现/历史定标记录，不扩展为培养参数。

展示尺寸先由单位概念体型确定，不能让所有单位各自撑满相同适配框而抹平体量差。当前三档以大型展示体量为100%：

| 档位 | 基准单位 | 相对展示体量 |
| --- | --- | --- |
| 小型 | 陆战队员、幽灵 | 约60% |
| 中型 | 医疗运输机、坦克、不朽者 | 约80% |
| 大型 | 雷兽、大和战舰（当前配置名战列巡航舰） | 约100% |

- 只有大型允许占满座台或部分溢出座台；溢出不得遮挡相邻单位、费用或铭牌。小/中型保留相应占幅，不独立放大至满台。
- 特殊相对关系及R4真实素材样件已获用户“合适，执行吧”批准：哨兵、感染虫50%；追猎者、刺蛇70%。原11卡档位保持；2026-11-11用户确认补齐剩余5卡：蟑螂2201、异龙2203为80%，狂热者2302、高阶圣堂武士2306为60%，风暴战舰2305为100%。当前16卡统一按可见主体定标，不以图片画布大小或职业推定。

# 卡牌与生产建筑对应规范

确认日期：2026-10-22；补充确认：2026-10-26。状态：现行。适用于卡组、兵种卡牌、格子解锁结果、生产建筑关联及相应美术资源规划。

## 已确认规则

- 格子解锁结果对应作战兵种卡牌时，立即建成该兵种对应的生产建筑；该建筑自动周期性产出对应兵种。
- 玩家在卡组中配置作战兵种卡牌，不再将它对应的生产建筑作为另一张卡牌重复配置。
- 对应关系由业务配置明确管理，不根据建筑名称、外观或图片资源反推兵种。当前字段入口为 CardResource 的兵种内容 unitId → UnitResource → UnitProductionResource 的 buildingId → BuildingResource；已接入正式配置、解锁建造及周期产兵；卡面展示实施状态见下文。
- “船坞”只是适用于特定兵种的生产建筑，不是全部产兵建筑的统一名称或外形。
- 示例：步兵卡牌对应步兵训练营，骑兵卡牌对应骑兵马厩。示例用于解释对应关系，不代表已确认殖民军包含骑兵或本轮需要制作马厩。
- 基地开局自带，不进入玩家可选卡组。采集站的固定卡组规则见下节。

## 卡组与初始卡牌（2026-10-26确认）

- 卡组上限8张，不允许重复卡牌；上限不是开局必须装满8张。
- 采集站固定1张，占用一个槽位，不可移除或替换。
- 当前测试卡组为采集站＋优秀/稀有/史诗/传说步兵＋稀有女妖战机，共6张，各有独立卡牌ID；替代此前5张占位卡组描述。女妖由机场生产，覆盖全部四档兵种品质。
- 玩家和敌方当前使用相同的六张测试卡；不由此推导后续玩家改卡组时敌方实时复制。
- 四档兵种暂复用现有步兵兵营图片及步兵动画，以独立配置引用区分，后续可替换正式资源。占位不代表四种正式兵种已制作完成，不擅自赋予更高品质额外战斗属性。
- 四档占位步兵当前每10秒产1兵，女妖按独立生产配置；不提前应用按品质改变生产速度或产量的成长规则。牌库及BattleDeckResource卡组样例已填写。
- 初始拥有卡牌不等于开局直接在场景生成对应建筑；开局仍仅双方各一个基地。
- 种族、开局货币、生产周期、人口限制和进度等待规则见[战斗初始化与建筑生产规范](战斗初始化与建筑生产规范.md)。格子支付与抽取规则见[格子解锁规则](格子解锁规则.md)。

本节替代此前关于采集站仅“可以在卡组内”的不完整描述及初始仅两张牌的测试方案。卡组、解锁、产兵与自动普攻已接入；卡牌升级效果仍待另行对齐。样例留空项及资源缺项见[战斗初始化与建筑生产规范](战斗初始化与建筑生产规范.md)的配置落位记录。

## 对美术制作的约束

- 生产建筑制作前明确对应兵种及产出对象，再决定建筑名称、识别特征和资源清单。
- 不从一张概念参考图自动扩展正式兵种清单或推导玩法能力。
- 尺度、锚点、朝向及批量对比遵守[战斗场景元素表现规范](战斗场景元素表现规范.md)。规则确认不等于建筑造型、尺寸或运行时已验收。


## 解锁卡牌展示（2026-10-29确认）

- 卡面的明确用途包括战斗中格子解锁结果展示，不再将该用途列为可选，也不以卡组编辑界面作为唯一设计基准。
- 付费成功后，建筑立即逻辑建成并从0开始生产计时；同时在对应格子短暂展示实际抽中的卡牌，结束后消失。动画不触发或延迟扣费、抽取、建造、生产，不等待动画回调。
- 兵种卡对应其生产建筑，采集站卡对应采集站。卡牌只作结果反馈，不永久占据格子，也不改变当前不消耗卡组卡牌的规则。
- 结果事件与空结果约定见[格子解锁规则](格子解锁规则.md)；场景节点生命周期见[场景管理规范](../通用规范/场景管理规范.md)；尺寸与首版样板参数见[战斗场景元素表现规范](战斗场景元素表现规范.md)。
- 首版场景样板使用现有CardResource.image及简单品质色块边框；当前步兵卡引用兵营图是历史占位，不代表正式兵种卡面定稿。先验收场景大小、锚点、节奏，再制作正式步兵/采集站卡面。

## 同品质抽取权重（2026-10-30）

`CardResource.unlockWeight`用于格子解锁命中品质后的兵种卡抽取，必须为正整数；当前测试值及最终概率统一见格子解锁规则，不将个别卡牌权重作为永久规则。费用、品质结果权重仍归CellUnlockResource，具体概率以[格子解锁规则](格子解锁规则.md)为权威。固定采集站分支不参与此加权抽取。

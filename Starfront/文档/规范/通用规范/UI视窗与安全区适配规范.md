# UI视窗与安全区适配规范

状态：现行规则，2026-10-30确认。规范约束与模板实现迁移分别记录；本次仅回写文档，不代表模板已具备样例项目全部适配实现。

## 设计与布局职责

- 设计分辨率和横竖屏方向由项目配置提供，通用框架与Skill不得写死某个项目尺寸。旧Prefab根尺寸不作为项目方向或完整界面设计基准的推断来源。
- 设计空间、实际视窗、设备安全区及平台遮挡区域分别管理；设备变长不要求重做设计稿。
- 按界面声明全屏舞台、完整内容等比容纳、独立窗口或定位提示策略，不能让所有界面统一铺屏或统一缩小。
- 背景与关键内容分离：声明可延伸的背景覆盖实际视窗，文字、按钮和重要信息位于可用区域。背景身份由配置或绑定明确，不按名称猜测。

## 公共区域与平台边界

- 公共服务统一提供实际视窗、设备安全区域和平台遮挡区域，界面消费其结果，不各自查询SDK或写死手机偏移。
- 设备安全区不等于小游戏胶囊区域。顶部整排避让或局部避让由项目策略声明；整排策略取设备顶部安全边距与胶囊底边加间距的较大约束，不重复累加。
- 平台适配器负责平台识别、SDK接口及逻辑像素转换；基础层接收通用区域，不依赖某个平台SDK。未接入的平台只使用已知设备安全区，不声称支持其操作按钮避让。
- 坐标转换明确原点、单位、像素比例和父容器，平台坐标只归一化一次；再转换到UI局部空间。输入命中与视觉变换保持一致。
- 屏幕尺寸、方向或平台区域变化后刷新布局；无效平台数据回退到有效设备安全区，保留可诊断状态。

## safeContent生命周期

- safeContent是公共适配层管理的运行时内容容器，不要求每个Prefab人工嵌套。初始化与复用必须幂等，不重复嵌套、不累计缩放或偏移。
- 完整界面使用项目设计尺寸；独立弹窗显式声明自身内容尺寸，不以弹窗尺寸反推项目横竖屏。
- 保持原绑定、监听和语义布局；关闭、销毁时清理适配监听。重新打开或恢复安全区时还原布局基线。
- 已有专用适配器的HUD不再套第二层相同避让；定位型提示需要独立的遮挡碰撞处理，不默认整屏缩放。

## 验收与回写

- 适配实现改动覆盖横屏和竖屏项目配置、不同设计尺寸及屏幕长宽比，检查完整内容边界、背景覆盖、输入命中、重复开关/初始化与区域恢复。
- Editor模拟与真机分开记录。平台胶囊、挖孔及底部手势区域需目标平台真机验证；模拟通过不能代替平台接口验收。
- 记录验证对象、版本和未覆盖项；已发布不等于真机通过。规则回写不自动包含模板代码迁移、构建、发布或Git提交。

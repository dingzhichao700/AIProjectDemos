# 卡牌与生产建筑对应规范

确认日期：2026-10-22；补充确认：2026-10-26。状态：现行。适用于卡组、兵种卡牌、格子解锁结果、生产建筑关联及相应美术资源规划。

## 已确认规则

- 格子解锁结果对应作战兵种卡牌时，立即建成该兵种对应的生产建筑；该建筑自动周期性产出对应兵种。
- 玩家在卡组中配置作战兵种卡牌，不再将它对应的生产建筑作为另一张卡牌重复配置。
- 对应关系由业务配置明确管理，不根据建筑名称、外观或图片资源反推兵种。当前字段入口为 CardResource 的兵种内容 unitId → UnitResource → UnitProductionResource 的 buildingId → BuildingResource；已填写首版占位样例，尚未导表或运行接入。
- “船坞”只是适用于特定兵种的生产建筑，不是全部产兵建筑的统一名称或外形。
- 示例：步兵卡牌对应步兵训练营，骑兵卡牌对应骑兵马厩。示例用于解释对应关系，不代表已确认殖民军包含骑兵或本轮需要制作马厩。
- 基地开局自带，不进入玩家可选卡组。采集站的固定卡组规则见下节。

## 卡组与初始卡牌（2026-10-26确认）

- 卡组上限8张，不允许重复卡牌；上限不是开局必须装满8张。
- 采集站固定1张，占用一个槽位，不可移除或替换。
- 首版测试卡组为采集站卡＋优秀、稀有、史诗、传说各一张兵种卡，共5张，各有独立卡牌ID。原初始两张方案为采集站与步兵，现按用户采纳的四品质覆盖方案扩充，避免抽取品质没有候选。
- 玩家和敌方首版使用相同的固定五张卡；不由此推导后续玩家改卡组时敌方实时复制。
- 四档兵种暂复用现有步兵兵营图片及步兵动画，以独立配置引用区分，后续可替换正式资源。占位不代表四种正式兵种已制作完成，不擅自赋予更高品质额外战斗属性。
- 首版占位兵种统一每10秒产1兵，只验证解锁与生产流程；不提前应用按品质改变生产速度或产量的成长规则。牌库及BattleDeckResource卡组样例已填写。
- 初始拥有卡牌不等于开局直接在场景生成对应建筑；开局仍仅双方各一个基地。
- 种族、开局货币、生产周期、人口限制和进度等待规则见[战斗初始化与建筑生产规范](战斗初始化与建筑生产规范.md)。格子支付与抽取规则见[格子解锁规则](格子解锁规则.md)。

本节替代此前关于采集站仅“可以在卡组内”的不完整描述及初始仅两张牌的测试方案。当前已落源表，运行时尚未接入；攻击、卡牌升级效果后续另行对齐。样例留空项及资源缺项见[战斗初始化与建筑生产规范](战斗初始化与建筑生产规范.md)的配置落位记录。

## 对美术制作的约束

- 生产建筑制作前明确对应兵种及产出对象，再决定建筑名称、识别特征和资源清单。
- 不从一张概念参考图自动扩展正式兵种清单或推导玩法能力。
- 尺度、锚点、朝向及批量对比遵守[战斗场景元素表现规范](战斗场景元素表现规范.md)。规则确认不等于建筑造型、尺寸或运行时已验收。

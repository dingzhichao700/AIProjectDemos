## 二、每角色参数记录模板

以下模板为记录格式，不是已经存在的游戏配置表。相同角色不同骨架/构图/版本分别记录，多个用途共用源图时引用源记录并列用途差异。

### A. 身份、来源和版本

| 字段 | 填写内容 |
|---|---|
| recordId / revision | 稳定技术标识、当前版本、负责人/会话、阶段与变更来源 |
| 角色与用途 | 角色身份、业务ID（已核实才填）、朝向、展示/战斗用途、实际使用入口 |
| 源资产 | 路径、GUID、SHA256、来源/许可、批准版本、单图或拆件；源图保护要求 |
| approvedStatic / approvedAnchor | 静态立绘形象确认版本/依据；锚点确认版本/依据；两项确定后才准入蒙皮制作，通用规则见主规范 |
| 环境 | Unity/2D Animation及相关包实际版本、渲染管线、目标平台；依赖锁位置 |

### B. 尺寸、画布和导入

| 字段 | 填写内容 |
|---|---|
| sourceCanvasPx / deliveryCanvasPx | 原图与交付画布宽高；不同则写处理方法和版本 |

| importedSizePx / importSettings | 实测纹理尺寸、PPU、NPOT/最大纹理尺寸/压缩/MipMap/透明处理 |
| usageDisplay | 每使用端的设计空间、显示矩形、绑定姿态主体占幅、缩放及最大显示倍率 |
| animatedBounds / padding | 动作包围范围、裁切边界与余量；测量的动作、相位、单位及方法 |

### C. 锚点、骨骼、网格和权重

| attachments / layers | 挂点的骨骼/局部变换/用途；拆件清单、层序和关节覆盖，无则注明 |

### 骨骼与网格

绑定姿态：下表局部坐标单位为Unity单位，全部局部旋转0°、缩放(1,1,1)，只在本试样PPU100映射下成立。

| 骨骼 | 父节点 | 局部位置(x,y,z) | 长度 |
|---|---|---|---|

网格21×41=861顶点、1600三角形；每顶点最多两骨影响。固定脚部；按本地Y在0.5–1.05、1.05–1.7、1.7–2.05区间分别线性过渡feetRoot→pelvis→chest→head，区间外钳制到端点。该规则只是单图试验权重，不保证适合其他角色关节或正式硬质装甲。网格/骨骼/权重保存在副本`soldier.png.meta`的官方Sprite编辑数据中。

### idle动作

- 原地循环、4秒周期，无根运动/动作事件。驱动为`Assets/CharacterTest/SoldierIdlePreview.cs`，不是已交付Animator动作库。
- 时间源：Unity `Time.time`（秒），φ=t×π/2。pelvis局部Z角=sin(φ)×1°；chest局部Z角=sin(φ+0.4)×−0.65°；head局部Z角=sin(φ+0.8)×0.65°。
- chest局部Y=绑定Y+(1−cosφ)×0.008，位移范围0–0.016 Unity单位；相位偏移0.4/0.8的单位为弧度。
- 暂停按钮停止写入姿态，但全局Time.time继续走，恢复可能跳到当前相位；当前不声称连续相位暂停/恢复已实现。正式动作切换、中断、速度范围、关闭复用、独立相位及最终动作边界未验证。
